# query

Jakich pakietów Java programista nie musi dołączać do aplikacji?
Pakiety te są "automatycznie" dołączane.

# answer

Pakiety `java.lang.*`

- Object, String, Integer, Double, Boolean, Math
- Thread, Runnable, Process, System
- Exception, RuntimeException, NullPointerException, Throwable
